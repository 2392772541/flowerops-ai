# FlowerOps 产品需求文档（PRD）

## 1. 背景

鲜切花具有保鲜期短、质量变化快、节日需求波动大、供应价格变化频繁等特点。传统进销存能记录订单和库存，却很难主动回答“哪些货会损耗”“周末会缺什么”“应先采购还是促销”等经营问题。

## 2. 目标用户

- 花店店长：关注毛利、损耗、库存和异常决策。
- 采购：关注未来需求、在途、价格和供应商可靠度。
- 仓管：关注批次、质量冻结、预留、效期和流水。
- 销售/客服：关注订单履约、客户信用和催款。

## 3. 核心问题

1. 账面库存不能代表实际可售库存。
2. 花束订单必须展开为多种原料需求。
3. 临期库存和未来订单需要放在同一时间轴分析。
4. AI 建议如果直接写入业务数据，风险不可控。
5. AI 结论若没有证据链，经营者无法信任。

## 4. MVP 范围

八个页面：经营总览、AI 决策中心、订单、批次库存、采购、客户应收、经营问数、审计。

核心闭环：发现异常 → 证据诊断 → 动作提案 → 人审 → 幂等执行 → 审计。

## 5. 非目标

- 不替代完整 ERP、财务或供应链系统。
- 不处理真实付款、短信、微信或供应商接口。
- 不使用合成数据声称降本增效成果。
- 不允许 AI 执行不可逆或高风险操作。

## 6. 成功指标

产品指标：建议查看率、证据展开率、提案批准率、拒绝原因分布、执行成功率、重复执行拦截率。

模型指标：异常识别准确率、建议可执行率、引用正确率、无证据拒答率和人工修改率。

业务指标（真实试点后才能测量）：缺货率、损耗率、库存周转、毛利率、应收逾期率。
