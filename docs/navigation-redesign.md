# 业务流程重新设计

2026-09-09

- 首页改为经营工作台，面试说明放到独立辅助入口。
- 导航采用 URL 路由与真实链接，支持详情页刷新、前进后退及复制地址。
- 采购：搜索、状态筛选、新建草稿、详情、提交审批、批准、记录下单、整单验收、对账、关闭。
- 收货原子新增批次、库存流水与审计事件；拒绝跳级、过期日期和重复收货。
