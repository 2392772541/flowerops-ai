# 评测与验收方案

## 自动化规则测试

当前 Vitest 覆盖：

1. 可售库存扣除预留、冻结和过期量。
2. 临期批次按新鲜度系数折算。
3. 库存汇总由批次事实重算。
4. 花束订单正确展开花材配方。
5. 建议采购量不为负数。
6. 需求预测权重透明且可复现。
7. 未批准提案无法执行。
8. 批准后只创建采购草稿并记录审计。
9. 相同幂等键重复执行不产生第二张采购单。

## 产品验收

- 无 API Key 可以跑通完整审批闭环。
- 页面明确标注合成演示数据。
- AI 建议展示数据证据和结果边界。
- 拒绝提案不产生业务写入。
- 执行后能在采购中心与审计中心找到对应结果。
- Demo 可重置，可导出 JSON。
- 桌面端和 390px 移动端无关键内容不可达。

## 后续真实模型评测

建立至少 50 条经营问题评测集，分别标注：意图、所需数据表、正确指标、期望结论、允许动作、必须拒绝的动作。比较规则 Provider 与不同模型 Provider 的准确率、引用正确率、延迟、成本和人工修改率。
